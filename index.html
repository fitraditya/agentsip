Built for real telephony, not just demos

Everything you need to run AI voice agents for inbound calls in production.

Real-time Pipeline

Low-latency streaming STT → LLM → TTS designed for natural, interruptible conversations.

Native SIP / RTP

Register as a SIP endpoint and receive calls from your PBX / inbound SIP trunk. No proprietary system required.

Modular Providers

Swap OpenAI, Deepgram, ElevenLabs, Whisper, and more. Bring your own keys and models.

Start in minutes

terminal 
git clone https://github.com/fitraditya/agentsip.git
cd agentsip
cp .env.example .env   # add your API keys
docker compose up

# AgentSIP is now ready to receive inbound SIP calls!
